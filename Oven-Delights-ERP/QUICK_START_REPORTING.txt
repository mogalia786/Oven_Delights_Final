STEP 1: RUN SQL SCRIPTS (5 minutes)
────────────────────────────────────────────────────────────────────
Open SQL Server Management Studio and run these files in order:

1. SQL\Create_Report_StoredProcedures.sql
2. SQL\Create_Additional_Report_Procedures.sql

You should see: "All report stored procedures created successfully!"

STEP 2: WIRE UP MENU (2 minutes)
────────────────────────────────────────────────────────────────────
Find your MainDashboard.vb file and add this to MainDashboard_Load:

    ' Setup Reporting Menu
    If ReportingToolStripMenuItem IsNot Nothing Then
        ReportingMenuSetup.SetupReportingMenus(Me, ReportingToolStripMenuItem)
    End If

STEP 3: BUILD & RUN
────────────────────────────────────────────────────────────────────
1. Press Ctrl+Shift+B to build
2. Press F5 to run
3. Click "Reporting" menu
4. Select any report!
